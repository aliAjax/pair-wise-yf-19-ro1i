# hxyfront-62007 植物标本馆 · 同物种批量鉴定复核

植物标本馆馆藏柜位的「同物种批量鉴定复核 + 按物种代码迁柜」前端工作台。

## 业务流程

1. **按物种组批**：鉴定员从待鉴定标本中按物种代码勾选组批。
2. **复核规则**：组内采集人不同，或海拔差超过 300 米时，批次须写明复核依据（支持批量套用、逐份修改）；缺说明的标本不进入本次结论，继续保留在待鉴定，并记录排除原因。
3. **统一写入**：复核通过后，批次内通过的标本统一写入鉴定人与鉴定日期。
4. **按物种代码迁柜**：每个物种代码对应指定柜层，通过后自动迁移占位。
5. **满位暂停**：目标层满位时暂停迁移——鉴定结论保留，标本留在原柜；可在迁移队列中从该层空位逐份重新选择（或自动补迁）。柜位整理时可对已上柜标本退架释放位号。
6. **同步与持久化**：柜位轨迹、待鉴定计数、状态筛选、标本详情实时同步；数据只存浏览器 localStorage，重开页面仍可查询。

## 页面

- **批量鉴定复核**：待鉴定按物种分组（展示组内采集人/海拔差判定）、批次逐份复核依据、通过并迁移。
- **柜位迁移**：待迁/满位暂停队列、A/B/C 柜各层柜格视图（层容量、空位、位号）、层详情与退架。
- **标本总览**：状态筛选（待鉴定 / 已鉴定待迁柜 / 迁柜暂停 / 已入库）、检索、录入新标本。
- **标本详情**：全部鉴定信息与完整柜位轨迹（入库 / 迁移 / 满位暂停 / 退架）。

## 技术栈

React 19 + Vite 7 + TypeScript，无后端，localStorage 持久化（键：`herbarium-batch-review-v1`）。
